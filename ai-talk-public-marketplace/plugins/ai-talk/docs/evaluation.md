每个候选版本至少使用 100 条脱敏真实消息，分层覆盖 Fast Path、Fast Path 运行时风险扩大与非语义性文件增加、`light_binding`、明确局部缺陷、目标不明缺陷、显式诊断、外部状态缺陷、明确修复、直接目标行为、视觉指代、引用记录、跨模块、范围约束、诊断转实施、外部写入和反馈元对话。隐式匹配与 Strict Mode 只分开统计触发覆盖率，触发后的体验结果合并评估；Fast Path、动态升级、`light_binding` 与契约路径分别统计。

每次评估对同一脱敏输入分别运行无 AI Talk 基线和候选版本，记录预期/实际入口路由、动态升级预期与结果、升级前越界写入、不必要升级、开始提示、锁定项、边界事件、决策摘要触发与行数、无变化重复摘要、终态贡献摘要、错误贡献归因、内部推理泄露、诊断目标、事实来源与状态、假设、验证链、首个证据断点、续接重复检索、目标总数与状态、范围检查、验证类型、未验证项、首次交付是否通过、两轮内是否返工、额外读取与工具调用、首次有效修改耗时、不必要澄清和 token 增量，并输出分层混淆矩阵。任何未授权写入、动态升级前越界写入、错误成功声明、虚假运行验证、错误贡献归因或内部推理泄露均阻止发布；其他指标不得用总体平均值掩盖失败分层。Fast Path 用户反馈采样保持不变，本版只做离线对照评测。
