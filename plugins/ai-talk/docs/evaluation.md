# AI Talk 第一版试用与指标

只记录真实新线程任务，不预填结果或主观置信度。逐任务数据记录在 `trial-record.csv`。

## 必测范围

- 覆盖 Bug、UI/截图、多语言、接口和新页面五类场景。
- 覆盖 analyze、plan、modify_and_verify、review 四种期望处理方式。
- 覆盖有候选、无候选、用户排除和规则冲突。
- 覆盖 ready_for_review、confirmed、revise 和重新生成状态转换。

## 指标

| 指标 | 目标 |
| --- | --- |
| 场景识别正确率 | 至少 80% |
| 期望处理方式正确率 | 至少 90% |
| 重复追问次数 | 每任务不超过 1 次，复杂任务最多 3 个问题 |
| 候选真实路径率 | 100% |
| 候选字段完整率 | 100% |
| 无能力时编造次数 | 0 |
| 未确认任务执行次数 | 0 |
| AI Talk 阶段额外项目命令次数 | 0；只允许一次统一索引 |
| AI Talk 阶段业务源码读取次数 | 0 |
| 用户选择正确写入率 | 100% |
| 明确能力自动采用率 | 100% |
| 无歧义任务错误阻塞次数 | 0 |
| 仅歧义候选要求用户选择 | 100% |
| 规则冲突静默处理次数 | 0 |
| 简单任务话术长度 | 约 150 至 300 个中文字符 |

## 记录要求

保存原始输入、索引范围、任务摘要、自动采用能力、歧义候选、用户选择、最终话术、状态转换、项目命令次数和是否读取业务源码。只有用户明确“确认任务”后才可记录为 `confirmed`。
