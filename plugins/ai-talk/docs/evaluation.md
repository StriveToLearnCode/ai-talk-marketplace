# AI Talk 试用与指标

只记录刷新 cachebuster、重新安装插件后的全新线程任务。逐任务数据记录在 `trial-record.csv`。

## 必测范围

- `direct`：纯文案、语法、明确机械修改、Bug 定位和简单 review。
- `discovery`：新增交互、业务逻辑、页面功能，以及功能与测试组合任务。
- 覆盖单文件、3 文件、4 文件、超过 64KB、存在 imports、文件不可读和 URL 场景。
- 覆盖多模块截图、点击区域歧义、现状/目标/细节多图，以及无需映射的纯文本简单任务。
- 覆盖普通 UI 开发、明确要求 UI 自测、独立修复自测、只检查模式和浏览器环境不可用。
- 覆盖 OpenAPI 已类型化响应、nullable/optional、真实不可信输入边界、缺少生成类型和真实响应违反契约场景。
- 提示词中包含 `$gen-code`、`$ai-test`、Figma、飞书或 Chrome 时，验证当前轮仍不执行。
- 覆盖 analyze、plan、modify_and_verify、review 四种后续处理方式。

保存原始输入、处理路径、起止时间、总耗时、明确文件列表、实际读取文件与字节数、未读取文件及原因、直接证据、AI 语义判断、对应关系、建议（非需求）、待确认信息、是否明确要求 UI 自测、是否写入 UI Self Check、UI 自测模式、Skill-only 命令和耗时、frontmatter 候选、话术中指定 Skill 及顺序、依赖读取数、下游 Skill/reference 调用数、外部工具调用数、已类型化字段降级 unknown 次数、无依据 normalize helper 次数、无依据业务校验次数、静默字段 fallback 次数、最终提示词和固定未执行声明。所有执行类字段必须为 0。
