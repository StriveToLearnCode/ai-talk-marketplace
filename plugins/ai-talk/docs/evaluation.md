# AI Talk 试用与指标

只记录刷新 cachebuster、重新安装插件后的真实新线程任务。逐任务数据记录在 `trial-record.csv`。

## 必测范围

- 覆盖 Bug、UI/截图、多语言、接口和新页面五类场景。
- 覆盖 analyze、plan、modify_and_verify、review 四种期望处理方式。
- 覆盖公司组件唯一明确结果、多个候选、Skill 失败、Skill 空结果、低相关结果、项目候选和新建本地组件。
- 覆盖最小模糊需求、用户明确补充、项目事实、组件能力与业务需求分离、显式建议请求。
- 覆盖 `prompt_state: draft / ready`。

## 指标

| 指标 | 目标 |
| --- | --- |
| 场景识别正确率 | 至少 80% |
| 期望处理方式正确率 | 至少 90% |
| 专用 Skill 实际调用率 | 100% |
| 通用 Skill 错误覆盖专用 Skill 次数 | 0 |
| Skill 结果真实路径或标识率 | 100% |
| 无来源需求条目数 | 0 |
| Assumption 被写成 Fact 次数 | 0 |
| 组件能力泄漏为业务需求次数 | 0 |
| 项目事实来源标注率 | 100% |
| 非阻塞缺失项冗余展示次数 | 0 |
| 用户未明确时生成验收标准次数 | 0 |
| 组件检索预设组件名称次数 | 0 |
| 公司组件候选数量超过 3 次数 | 0 |
| 公司组件候选展示额外字段次数 | 0 |
| 公司与项目组件混合展示次数 | 0 |
| 公司组件无结果时自动降级次数 | 0 |
| 未选择候选前生成最终话术次数 | 0 |
| Skill 失败或空结果编造次数 | 0 |
| 用户 Skill 目录和插件缓存扫描次数 | 0 |
| 无能力时编造次数 | 0 |
| AI Talk 阶段业务文件修改次数 | 0 |
| AI Talk 阶段 formatter、lint、测试、构建次数 | 0 |
| 伪确认、取消或开始按钮输出次数 | 0 |
| 用户选择正确写入率 | 100% |
| 规则冲突静默处理次数 | 0 |
| 简单任务话术长度 | 约 150 至 300 个中文字符 |

## 记录要求

保存原始输入、用户事实、带来源的项目事实、检索事实、阻塞性未知、Assumption 或建议、Available Skills、实际查询词、实际调用 Skill、推荐确定性、候选展示、用户选择和最终话术。逐条检查最终需求是否可追溯到允许来源，不得仅根据文档声明通过。
