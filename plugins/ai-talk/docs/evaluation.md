# AI Talk v3 试用与指标记录

本文件只定义采集和计算方式，不预填任何试用结果。逐任务数据记录在 `trial-record.csv`。

## 试用要求

- 邀请 2 名 Codex 新用户、2 名重度用户和 1 名负责人或带新人同事。
- 每人至少使用 2 个真实任务，直接输入原本准备交给 Codex 的表达。
- 不提前教授 Prompt 写法；记录用户选择继续、生成话术还是调整，发现了哪些候选能力、最终组合和实际复用对象，是否发生复制粘贴，确认后是否直接开始处理，以及是否返工和再次使用。
- 至少收集 10 个任务，覆盖 Bug、UI/多语言、接口联调三个核心场景，并保留至少 3 个完整前后对比案例。

## 指标口径

| 指标 | 计算方式 | v3 目标 |
| --- | --- | --- |
| 平均追问次数 | Codex 追问次数总和 / 有效任务数 | 不超过 1 次 |
| 首轮理解正确率 | “是否理解正确”为是的任务数 / 有效任务数 | 至少 80% |
| 摘要无需调整比例 | 首次摘要后直接选择“继续处理”的任务数 / 有效任务数 | 至少 70% |
| 确认后直接处理率 | 选择“继续处理”后未重新发送完整需求的任务数 / 继续处理任务数 | 100% |
| 任务转交复制粘贴次数 | 默认确认路径中发生复制或粘贴完整话术的次数 | 0 次 |
| 无关修改次数 | “是否修改无关文件”为是的任务数 | 低于直接提问基线 |
| 能力候选准确率 | 经读取确认适用的候选数 / 被 AI Talk 推荐的候选数 | 至少 80% |
| 已有能力复用率 | 实际复用至少一个已有 Skill、Prompt、组件、函数或规范的任务数 / 存在适用能力的任务数 | 至少 80% |
| 重复实现次数 | 已存在适用能力但仍新增同类组件、函数或流程的任务数 | 低于直接提问基线 |
| 首轮完成率 | “是否首轮完成”为是的任务数 / 有效任务数 | 与直接提问对比 |
| 一周重复使用率 | 一周内再次使用人数 / 试用人数 | 至少 60% |

## 前后对比

对同类任务分别记录“直接提问”和“使用 AI Talk”的平均追问次数、首轮理解正确率、能力发现与实际复用情况、重复实现次数、无关修改次数、首轮完成率、平均沟通轮次、确认后启动处理时间和验证方式完整度。没有真实数据时保持空白，不用主观评分代替。

## 观察重点

- 第一条自然语言输入是什么，场景、执行意图和任务摘要是否识别正确。
- 主能力和辅助能力是否真实存在、是否读取确认、是否各自补足明确环节；无匹配时是否正确降级。
- 组件、函数、Prompt、规范和同类页面是否被实际复用，新增实现是否有明确的不适用理由。
- 用户选择继续、生成话术还是调整；调整了哪些内容，是否仍需 Codex 重复追问。
- 选择继续后是否直接开始处理，是否仍出现复制、滚动、粘贴或重新发送完整需求。
- 是否出现无关修改、无证据结论或需要重复描述背景的返工。
- 只根据真实记录调整规则，优先处理识别错误、摘要过长、上下文不贴合、重复确认和返工接续失败。
