# 接口联调

```text
请协助完成接口联调。接口文档是契约，现有代码是待核对实现；不要凭经验编造字段。

【资料】
- 接口文档/OpenAPI：{{api_doc}}
- 联调环境：{{environment}}
- 相关文件：{{files}}
- 当前问题：{{problem}}

【第一阶段：理解任务】
1. 提取请求方法、路径、参数、响应结构、错误码和鉴权方式。
2. 对照前端类型、请求封装、状态管理和页面消费位置。
3. 输出字段映射及不一致项，标明文档事实和代码推断。
4. 缺少正式契约时先列出阻塞项，不自行补造接口。

【第二阶段：执行任务】
1. 按契约完成最小范围适配。
2. 覆盖成功、业务失败、网络失败、空数据和重复请求状态。
3. 保留必要的联调日志，避免输出令牌或用户隐私数据。
4. 如果实际响应与文档不一致，记录样本并暂停有风险的字段改动。

【第三阶段：评估结果】
输出接口清单、字段映射、请求与响应验证结果、错误处理结果、修改文件、契约差异、待服务端确认项和可复现的联调步骤。
```
