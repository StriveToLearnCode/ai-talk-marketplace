# 接口联调

明确权威契约、页面消费方式、状态处理和联调证据。不得凭经验编造字段、错误码或鉴权规则。

## 必须补充

- 接口文档、OpenAPI 或真实请求响应样本，以及联调环境和鉴权前提。
- 请求方法、路径、参数和页面需要使用的响应字段映射。
- 与当前页面有关的加载、空数据、业务失败、网络失败、重复点击和重复请求状态。
- 文档、真实响应、现有代码和待服务端确认差异的区分。
- 真实请求响应与页面可观察结果作为验证依据。

没有正式契约时，把收集真实请求和响应证据写入任务目标；不要猜测字段后继续生成“已确认”的适配要求。不要输出令牌、用户隐私或其他敏感数据。

## 紧凑话术骨架

```text
# 任务话术

请根据【接口文档/OpenAPI/真实响应】联调【页面或模块】的【接口】。期望处理方式未明确时默认先给方案；当前任务话术必须先由用户审查，AI Talk 不修改代码。

以权威契约为字段依据，核对请求方法、路径、参数、鉴权、响应字段映射和错误码；覆盖加载、空数据、业务失败、网络失败、重复点击或重复请求。范围限定为当前模块及直接请求封装，不修改无关公共请求代码。

请输出字段映射、契约差异、页面状态处理、待确认项和基于真实请求响应的联调验证方式。
```
