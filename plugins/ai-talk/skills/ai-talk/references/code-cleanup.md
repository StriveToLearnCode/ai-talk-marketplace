# 代码清理

```text
请清理以下代码，目标是降低复杂度和重复，同时保持现有行为不变。

【范围】
{{files}}

【清理目标】
{{goal}}

【限制】
{{constraints}}

【第一阶段：理解任务】
1. 阅读目标代码并说明当前职责、依赖和调用关系。
2. 找出重复、废弃、命名不清、职责混杂和高风险区域。
3. 区分确定可清理项与需要业务确认的项。
4. 先给出最小清理计划，不要改变对外行为或接口。

【第二阶段：执行任务】
1. 小步修改，每一步保持代码可运行。
2. 不引入与目标无关的新抽象或依赖。
3. 删除代码前确认没有引用、动态调用或配置依赖。
4. 保留兼容性；无法证明安全的内容只报告，不删除。

【第三阶段：评估结果】
运行类型检查、测试或构建；输出修改前后差异、删除内容及依据、验证结果、潜在兼容风险和未处理项。
```
