# UI 还原与走查

```text
请对当前页面进行 UI 还原或走查，以设计稿为视觉基准，以现有业务逻辑为功能基准。

【资料】
- 页面地址：{{url}}
- 设计稿/Figma：{{design}}
- 相关文件：{{files}}
- 重点检查：{{focus}}

【第一阶段：理解任务】
1. 确认目标页面、语言、设备尺寸、页面状态和对照稿版本。
2. 列出需要比较的布局、尺寸、间距、字体、颜色、图片、动画和交互状态。
3. 区分设计差异、资源问题、数据问题和业务逻辑问题。

【第二阶段：执行任务】
1. 按页面区域逐项比对，并保留截图或可复核证据。
2. 优先定位产生差异的具体 DOM、样式、组件或资源路径。
3. 若要求修改，只修复已确认差异，不凭感觉重做设计。
4. 检查不同语言、长文本、空状态、加载状态和常见屏幕尺寸。

【第三阶段：评估结果】
按严重程度输出差异清单，每项包含位置、现象、设计预期、证据、原因和建议；若已修改，再提供修改文件、验证截图和仍需人工确认项。
```
