# AI Talk 第一版新线程验收

每个用例在刷新 cachebuster、重新安装插件后的全新 Codex 对话中运行。AI Talk 阶段只允许一次 `collect_context.py` 轻量索引，不得额外读取业务源码、定位根因、运行测试或修改文件。所有新任务必须停在 `ready_for_review`。结果必须保存真实输出，不能仅根据文档声明通过。

## 1. 榜单页面开发

输入：

```text
$ai-talk 帮我根据截图开发一个独立榜单页面。
```

通过条件：

- 同时识别 `ui_reconstruction` 和 `feature_development`。
- 不再询问页面位置；期望处理方式为 `modify_and_verify`。
- 搜索真实榜单 Skill、组件和同类实现，展示路径、原因、待验证和风险。
- 主 Skill、项目规则和唯一明确的项目实现自动采用；只有多个组件/方法竞争或共享能力适配不明确时才让用户选择。
- 生成话术后进入 `ready_for_review` 并停止。

结果：待新线程执行。
